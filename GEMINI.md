# 🤖 Инструкции для Gemini по проекту Песенника (Songbook)

Этот файл предназначен для быстрого ознакомления ИИ-ассистента (Gemini) с контекстом, архитектурой и правилами разработки проекта при каждом запуске.

---

## 📝 Обзор проекта

Проект представляет собой структурированную базу популярных песен на русском языке (преимущественно русский рок) в формате **ChordPro**. 

Проект решает три основные задачи:
1. **Хранение базы песен** в переносимом, структурированном текстовом формате `.cho`.
2. **Генерация качественных печатных документов** (индивидуальных PDF для каждой песни и единого песенника `songbook.pdf`) с помощью Perl CLI-утилиты `chordpro`.
3. **Развертывание интерактивного веб-сайта** на фреймворке **Astro** с возможностью динамического транспонирования аккордов на лету, автопрокрутки и просмотра встроенных видео-разборов.

---

## 📁 Структура директорий

При анализе проекта ориентируйся на следующую структуру:
- `/[Artist Name]/` — папки исполнителей (например, `Кино/`, `Король и Шут/`, `Сплин/`). Содержат песни в формате `.cho`.
- `/.chordpro.json` — конфигурационный файл рендеринга PDF (шрифты, отступы, диаграммы аккордов).
- `/Makefile` — команды автоматизации сборки PDF и управления сайтом.
- `/website/` — исходный код веб-приложения на Astro.
  - `/website/package.json` — зависимости веб-приложения (Astro, `chordsheetjs`, `fast-glob`).
  - `/website/src/utils/songParser.js` — парсер песен. Преобразует разметку `.cho` в структурированное дерево (AST) и генерирует семантическую HTML-разметку.
  - `/website/src/pages/` — маршрутизация сайта. Главный каталог (`index.astro`) и динамические страницы песен (`[artist]/[song].astro`).
  - `/website/src/components/` — интерактивные элементы UI (`Transposer.astro` для транспонирования, `AutoScroller.astro` для прокрутки).

## 📌 Правила добавления и форматирования песен (.cho)

Все файлы песен должны строго следовать стандарту ChordPro и правилам проекта:

0. **Сборка и генерация PDF (Важно для ИИ):**
   - При добавлении или изменении песен **НЕ ТРЕБУЕТСЯ** запускать команды сборки (`make site`, `make pdfs`, `make all` и т.д.) или генерировать PDF-файлы. 
   - Достаточно просто добавить/отредактировать файл песни в формате `.cho`. Никакие другие действия или запуски команд не требуются.

1. **Путь и имя файла:**
   - Путь: `songs/[Имя_Исполнителя]/[Имя_Песни].cho`
   - Имена папок исполнителей и файлов песен пишутся на русском языке (если исполнитель/песня русскоязычные).
   - В именах файлов пробелы заменяются на нижнее подчеркивание (например, `Звезда_по_имени_солнце.cho`).

2. **Обязательные мета-директивы (в начале файла):**
   - `{title: Название песни}` — заголовок песни.
   - `{artist: Исполнитель}` — имя исполнителя или группы.
   - `{key: Тональность}` — оригинальная тональность (например, `Am`, `G#m`, `D`).
   - `{tempo: Число}` — темп в BPM (например, `120`).
   - `{meta: video Ссылка}` или `{video: Ссылка}` — ссылка на YouTube с видеоклипом или видео-разбором. Интегрирует плеер на сайт.

3. **Разметка блоков песни:**
   - Куплеты оборачиваются в директивы `{sov}` (Start of Verse) и `{eov}` (End of Verse).
   - Припевы оборачиваются в `{soc}` (Start of Chorus) и `{eoc}` (End of Chorus).
   - Аккорды встраиваются непосредственно в текст песни перед слогом, на котором они должны звучать, в квадратных скобках (например, `[Am]Звезда по имени [C]Солнце`).

Пример правильно оформленного файла:
```text
{title: Группа крови}
{artist: Кино}
{key: F#m}
{tempo: 120}
{meta: video https://www.youtube.com/watch?v=i945nZpIe9M}

{sov}
[F#m]Теплое место, но [C#m]улицы ждут
[D]Отпечатков наших [E]ног.
[F#m]Звездная пыль — [C#m]на сапогах.
{eov}

{soc}
[Bm]Группа крови — на ру[D]каве,
Мой по[F#m]рядковый номер — на ру[C#m]каве,
Поже[Bm]лай мне удачи в бо[D]ю, пожелай мне...
{eoc}
```

## 💻 Разработка веб-сайта (Важно для ИИ)

При изменении или доработке веб-интерфейса в папке `website/` строго соблюдай следующие принципы:

1. **Логика работы транспозера (клиентский скрипт):**
   - Парсер в `songParser.js` оборачивает каждый аккорд в тег `<span class="chord" data-original-chord="C">C</span>`.
   - Не удаляй и не переименовывай атрибут `data-original-chord`. Клиентский JS-код в `Transposer.astro` ищет элементы именно по классу `.chord` и использует `data-original-chord` в качестве исходной точки для расчета шагов транспонирования.
2. **Маршрутизация и слаги:**
   - Веб-сайт использует автоматическую транслитерацию кириллических имен с помощью функции `transliterate()` в `songParser.js` для формирования SEO-дружелюбных URL-адресов.
   - Пример: `Кино` -> `kino`, `Звезда по имени солнце` -> `zvezda-po-imeni-solntse`.
   - Шаблон пути к песне на сайте: `/songs/[artist-slug]/[song-slug]/`.

## 🛠️ Команды автоматизации (Makefile / justfile)

Используй эти команды (через `make` или `just`) для сборки и локальной разработки:

* `make all` или `just all` — собрать статическую версию сайта по умолчанию.
* `make pdfs` или `just pdfs` — сгенерировать только отдельные PDF-файлы для песен (ручной запуск).
* `make songbook` или `just songbook` — сгенерировать только общую книгу песен PDF (ручной запуск).
* `make dev` или `just dev` — запустить локальный сервер разработки Astro. Сайт будет доступен по адресу `http://localhost:4321/songs/`.
* `make site` или `just site` — собрать статическую версию сайта для продакшена в директорию `website/dist/`.
* `make clean` или `just clean` — удалить все сгенерированные `.pdf` файлы из папок проекта.
